# Public Open Payments primitives

Published as `@ijuba-labs/payment-primitives` in GitHub Packages from
[Ijuba Labs' public backend](https://github.com/Ijuba-Labs/digital-wallet-backend).
Release tags use `payment-primitives-v<version>` and must match this package's version.

Configuration-injected SDK URL validation, GNAP proof verification, and contextual grant encryption. No private repository, application database, JWT secret, or checkout policy is required. Build with `pnpm install && pnpm build`. Consumers may install this public package from this directory or an independently published artifact. Preserve old encryption keys while any credentials reference them.
